# Messenger

Веб-приложение для обмена сообщениями (SPA), разработанное в рамках курса "Мидл фронтенд-разработчик" от Яндекс.Практикума.

## Функциональность

- **Авторизация и регистрация**: Вход, регистрация, валидация форм.
- **Чаты**: Список чатов, создание новых чатов, удаление чатов.
- **Обмен сообщениями**: Отправка и получение текстовых сообщений в реальном времени (WebSocket).
- **Управление пользователями**: Добавление и удаление пользователей из чата (поиск по логину).
- **Профиль**: Просмотр и редактирование профиля, смена пароля, загрузка аватара.
- **Обработка ошибок**: Страницы 404 и 500.

## Технологии и инструменты

- **TypeScript**: Строгая типизация.
- **Handlebars**: Шаблонизатор для компонентов и страниц.
- **PostCSS**: Препроцессор CSS.
- **Vite**: Сборщик проекта.
- **Архитектура**: Компонентный подход (класс `Block`), Event Bus, собственный Router, HTTPTransport.
- **Тестирование**: Mocha, Chai, Sinon (unit-тесты).
- **Качество кода**: ESLint, Prettier, Stylelint, Husky, Lint-staged.

## Установка и запуск

**Предварительные требования**: Node.js >= 16.

1.  **Установка зависимостей**:
    ```bash
    npm install
    ```
    *При установке автоматически настроятся pre-commit хуки (husky).*

2.  **Запуск в режиме разработки**:
    ```bash
    npm run dev
    ```
    Приложение будет доступно по адресу `http://localhost:5173` (или другой порт, указанный в консоли).

3.  **Сборка проекта**:
    ```bash
    npm run build
    ```
    Результат сборки будет в папке `dist`.

4.  **Запуск production-сервера** (после сборки):
    ```bash
    npm run start
    ```
    Запускает простой Express-сервер для раздачи статики из `dist`.

## Тестирование

В проекте используются unit-тесты для ключевых модулей (`Router`, `Block`, `HTTPTransport`).

*   **Запуск тестов**:
    ```bash
    npm run test
    ```

## Линтинг и форматирование

*   **Проверка TypeScript**: `npm run type-check`
*   **ESLint**: `npm run lint` (автофикс: `npm run lint:fix`)
*   **Stylelint**: `npm run stylelint` (автофикс: `npm run stylelint:fix`)
*   **Prettier**: `npm run format`
